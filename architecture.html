Filter Data Flow

Every filter change triggers a full round-trip. All four filters (period, warehouse, category, status) are sent as query params on every request.

1
User changes a filter
FilterBar.vue renders four dropdowns. Selecting a value writes to the global useFilters composable.
// FilterBar.vue selectedLocation.value = 'San Francisco'
2
Watchers fire in every active view
Each view (Dashboard, Inventory, Orders…) watches all four filter refs and calls its own loadData() on any change.
// Dashboard.vue watch([selectedPeriod, selectedLocation, selectedCategory, selectedStatus], () => { loadDashboard() })
3
api.js builds the request
getCurrentFilters() assembles an object from the composable state; Axios appends it as query params.
// api.js const filters = { warehouse: 'San Francisco', category: 'Circuit Boards', status: 'all', month: '2025-01' } axios.get('/api/orders', { params: filters }) // → GET /api/orders?warehouse=San+Francisco&category=Circuit+Boards&month=2025-01
4
FastAPI receives and filters
Each endpoint delegates to apply_filters() for warehouse / category / status, then filter_by_month() for the time dimension.
// main.py @app.get('/api/orders') def get_orders(warehouse=None, category=None, status=None, month=None): result = apply_filters(orders, warehouse, category, status) result = filter_by_month(result, month) # handles YYYY-MM and Q1-2025 return result
5
Pydantic serialises the response
FastAPI validates each item against the declared response model and serialises to JSON automatically.
// Response — filtered JSON array [{ "id": "ord-001", "warehouse": "San Francisco", "category": "Circuit Boards", "status": "Delivered", ... }]
6
Vue re-renders
The view assigns the response to a ref. Computed properties derived from it update instantly; Vue patches only the changed DOM nodes.
// Orders.vue orders.value = response.data // triggers computed + template re-render

Key Design Patterns

Reactive Filter State
useFilters.js holds four ref() values shared across the whole app via Vue's composable pattern. Every view calls getCurrentFilters() to snapshot the current state and passes it to api.js. No Vuex / Pinia — composables are enough.
In-Memory Data at Startup
mock_data.py loads all JSON files once when the module is imported. All requests filter Python lists in-memory — no I/O per request. Dashboard KPIs are computed on each request from the filtered subset.
SVG Charts (No Library)
Charts are hand-rolled SVG. The donut uses stroke-dasharray segments per status. Horizontal bars use dynamic width: (value / max * 100)%. KPI progress bars are CSS width-controlled divs.
Centralised API Layer
All HTTP calls live in api.js — views never import Axios directly. This makes the base URL, auth headers, and error handling easy to change in one place.
Quarter / Month Filtering
The backend filter_by_month() handles both 2025-01 (exact month) and Q1-2025 (expands to Jan–Mar). Inventory endpoints skip month filtering entirely — stock has no time dimension.
i18n + Currency
useI18n.js provides a t() function and currency formatter. Switching to Japanese (JP) changes labels to ja.js strings and formats numbers as JPY. Preference persisted in localStorage.
